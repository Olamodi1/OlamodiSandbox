References and Resources

Standards documents and sources behind this site, plus good places to keep learning.

References

  1. Fielding, R. & Reschke, J. (2014). RFC 7230: HTTP/1.1 Message Syntax and Routing. IETF. rfc-editor.org/rfc/rfc7230
  2. Belshe, M., Peon, R., & Thomson, M. (2015). RFC 7540: Hypertext Transfer Protocol Version 2. IETF. rfc-editor.org/rfc/rfc7540
  3. Bishop, M. (2022). RFC 9114: HTTP/3. IETF. rfc-editor.org/rfc/rfc9114
  4. IETF QUIC Working Group. (2021). RFC 9000: QUIC: A UDP-Based Multiplexed and Secure Transport. rfc-editor.org/rfc/rfc9000
  5. MDN Web Docs. An overview of HTTP. Mozilla. developer.mozilla.org/en-US/docs/Web/HTTP/Overview
  6. Cloudflare. What is HTTP/3? cloudflare.com/learning/performance/what-is-http3
  7. W3Techs. Usage statistics of HTTP/2 for websites. w3techs.com/technologies/details/ce-http2
  8. Google. HTTPS encryption on the web, Transparency Report. transparencyreport.google.com/https/overview
  9. Berners-Lee, T. (1991). The Original HTTP as defined in 1991. W3C. w3.org/Protocols/HTTP/AsImplemented.html
  10. Let's Encrypt / ISRG. About Let's Encrypt. letsencrypt.org/about

Several RFCs above have newer replacements (for example, RFC 9110 to 9114 cover HTTP semantics, HTTP/1.1 and HTTP/2). The versions listed are the ones I originally used; I will update them in a later milestone.
